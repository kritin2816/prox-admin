📱 Mobile App Login Interceptor & Flagging Code

Add this check to your provider mobile app login / OTP handler. When a deleted provider attempts to log in, it automatically rejects them and triggers a real-time flag on this admin dashboard. 

// When provider submits OTP / logs in with auth UID:
const deletedRef = db.collection('deleted_providers').doc(user.uid);
const deletedSnap = await deletedRef.get();

if (deletedSnap.exists) {
  // 1. Flag the attempt in Firestore (Real-time alert on Admin Dashboard)
  await deletedRef.update({
    hasLoginAttempt: true,
    flaggedForReview: true,
    loginAttemptsCount: firebase.firestore.FieldValue.increment(1),
    lastLoginAttemptAt: firebase.firestore.FieldValue.serverTimestamp(),
    loginAttemptLogs: firebase.firestore.FieldValue.arrayUnion({
      attemptedAt: new Date().toISOString(),
      method: 'phone_otp_login',
      device: navigator.userAgent || 'Provider Mobile App'
    })
  });

  // 2. Reject login and show prompt
  await auth.signOut();
  alert("Your provider account was previously deleted. Please contact Pro X Admin.");
  return;
}
